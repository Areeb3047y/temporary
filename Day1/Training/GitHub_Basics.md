# GitHub Basics

## What is a Problem?

Imagine you are writing a story.
*   You write Chapter 1. You save it.
*   You write Chapter 2. You save it, and the old Chapter 1 is gone.
*   Now, you want to see the old Chapter 1. But you can't. It is lost.

This is a problem for programmers too. We write code, we change it, and sometimes we want to go back to the old code.

## Git and GitHub is the Solution!

**Git** is a tool on your computer. Think of it as a "save" button with a memory. When you save, it remembers the old version. You can go back in time to any saved version.

**GitHub** is a website. It's like a cloud storage for your Git projects. You can upload your saved versions to GitHub. This is useful for two reasons:
1.  **Backup:** Your code is safe, even if your computer breaks.
2.  **Teamwork:** You can share your code with friends. They can download it, make changes, and share it back with you.

## Basic Git Commands (Simple Words)

*   `git clone`: **Copy** a project from GitHub to your computer.
*   `git add`: **Choose** which files you want to save.
*   `git commit`: **Save** the chosen files. You must write a message to remember what you changed. (e.g., "I added a new picture").
*   `git push`: **Upload** your saved changes from your computer to GitHub.
*   `git pull`: **Download** the latest changes from GitHub to your computer.
