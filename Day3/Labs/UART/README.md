# Lab: UART

This lab will guide you through the process of using UART to send and receive data.

## Objectives

*   Configure UART on the STM32.
*   Send and receive data over UART.
*   Use a terminal emulator to view the UART output.

## Instructions

1.  Create a new STM32 project in STM32CubeIDE.
2.  Configure a UART peripheral (e.g., `USART1`) and the corresponding GPIO pins.
3.  Write the code to send the string "Hello, World!" over UART.
4.  Use a terminal emulator (e.g., PuTTY, Tera Term) to connect to the UART port and view the output.
5.  (Optional) Write the code to receive a character from the terminal emulator and echo it back.
