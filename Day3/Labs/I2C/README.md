# Lab: I2C

This lab will guide you through the process of using I2C to communicate with a peripheral device.

## Objectives

*   Configure I2C on the STM32.
*   Communicate with an I2C slave device (e.g., an EEPROM, a sensor).
*   Read and write data to the slave device.

## Instructions

1.  Connect an I2C slave device to your STM32 board.
2.  Create a new STM32 project in STM32CubeIDE.
3.  Configure the I2C peripheral and the corresponding GPIO pins.
4.  Write the code to read the device ID from the slave device.
5.  Write the code to write a byte of data to a register in the slave device.
6.  Write the code to read a byte of data from a register in the slave device.
