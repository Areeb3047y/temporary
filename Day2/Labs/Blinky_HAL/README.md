# Lab: Blinky with HAL

This lab will guide you through the process of creating a Blinky project using the HAL.

## Objectives

*   Create a new STM32 project in STM32CubeIDE.
*   Configure the clock and GPIO pin.
*   Write the code to blink the LED.
*   Build and run the project.

## Instructions

1.  Follow the steps in the [Creating a Blinky Project with HAL](./../Training/Blinky_HAL.md) guide to create your project.
2.  Make sure you select the correct board and LED pin for your hardware.
3.  Once you have completed the guide, you should have a working Blinky project.
