# Lab: Blinky with Register-Level Programming

This lab will guide you through the process of creating a Blinky project using register-level programming.

## Objectives

*   Understand how to configure the clock and GPIO pin using registers.
*   Write the code to blink the LED using registers.
*   Build and run the project.

## Instructions

1.  Create a new STM32 project in STM32CubeIDE.
2.  Instead of using the HAL, write the code to configure the clock and GPIO pin using registers as shown in the [Blinky with Register-Level Programming](./../Training/Blinky_Register_Level.md) guide.
3.  Write the code to blink the LED using the `ODR` register.
4.  Build and run the project.
